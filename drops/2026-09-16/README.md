# Brinefox — ChatGPT pet pack

Free ChatGPT companion pack from **Minzy Studios**.

**Brinefox** is an original sea-fox: slate-violet fur, translucent glass fins, bioluminescent teal whiskers. Calm tide-pool focus buddy for teens and young adults — not a product mascot, just a giveaway pet you can paste into ChatGPT.

## What's in this drop

| File | What it is |
| --- | --- |
| `PROMPT.md` | Personality / system prompt to paste into ChatGPT |
| `art/brinefox-portrait.png` | Square-ish reference portrait for custom GPTs / avatars |
| `art/brinefox-tidepool.png` | Tide-pool full-body still |
| `captions.md` | Social caption drafts (Mike owns publish) |

Mirrored under [`chatgpt-pets/brinefox/`](../../chatgpt-pets/brinefox/).

## How to use

1. Open ChatGPT → new chat (or Custom GPT instructions).
2. Paste everything in `PROMPT.md`.
3. Optional: attach `art/brinefox-portrait.png` as a visual reference.
4. Talk to Brinefox.
